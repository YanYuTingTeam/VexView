# VexView 2.7.3-1.8.9-r3 — Release Notes

Minecraft 1.8.9 / Forge 客户端移植版。本版本主要修复实体预览、HUD 排序及图片加载问题，并加强图片资源安全限制。

## 安装

1. 使用 Minecraft 1.8.9 和兼容的 Forge 客户端。
2. 将 `vexview-2.7.3-1.8.9-r3.jar` 放入对应游戏版本的 `mods` 文件夹。
3. 将旧版 VexView JAR 移出该文件夹，不要同时加载多个版本。

## 兼容性说明

本地 `[local]` 图片必须位于配置的资源目录内；超出目录或通过链接指向目录外的路径会被拒绝。普通图片最大尺寸为 4096 × 4096，单个本地或远程图片读取量最多 16 MiB，Base64 图片解码前的文件数据最多 8 MiB。GIF 帧数、总像素和图片任务队列也有限制，超过限制的资源可能无法显示。详情见 [图片资源限制](IMAGE-RESOURCE-LIMITS.md)。

## 构建与验证

- JAR 对应代码提交 `512f926e1380efebb34d064eb0c392681d860dbd`，使用 JDK 17 编译为 Java 8 字节码，并使用 Java 8 与现有 Forge 1.8.9 MCP 工具链进行重映射。
- 检查了 179 个 Java 8 class、25 个资源文件及 JAR 完整性。重映射报告的 3 个未映射引用与已有验证记录一致。
- 实体预览、HUD 排序、Base64 图片、本地路径、图片限制、连接隔离、队列饱和恢复及 HTTP 下载超时的回归测试通过。
- 用户报告已在服务器测试，需要使用的功能可以正常使用；未逐项记录测试覆盖范围。本次未重新运行旧版探针或 ForgeGradle 构建。
- 普通 URL/GIF 已上传的共享缓存尚无完整自动释放机制。
